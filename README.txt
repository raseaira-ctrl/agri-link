AGRI-LINK WEBSITE
Farmer-to-Consumer Marketplace System
Alibagon, Cajidiocan, Romblon

REQUIREMENTS
1. Visual Studio Code
2. A web browser such as Chrome
3. Live Server extension in VS Code (recommended)

HOW TO RUN
1. Open Visual Studio Code.
2. Select File > Open Folder.
3. Open the AGRI-LINK folder.
4. Make sure all HTML files, style.css, and app.js
   are inside the same folder.
5. Install the Live Server extension if needed.
6. Right-click index.html.
7. Select Open with Live Server.

FEATURES
- Homepage and product catalog
- Product search and category filter
- Product prices and stock counter
- Farmer name, phone number, and farm location
- Google Maps links
- Shopping cart and checkout
- Customer delivery address
- Order history and status
- Rider name and contact number
- Seller Centre for adding products
- Order management

IMPORTANT LIMITATIONS
This is a frontend school-project prototype.
It uses browser localStorage for data storage.
Data does not automatically sync between devices.
It has no secure login or real online payment.
Do not enter sensitive personal information.
A real public marketplace needs a backend,
database, authentication, and security.
